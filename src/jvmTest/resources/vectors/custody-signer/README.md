# Custody-signer vectors

ADR-0021's custody-signer suite. One body, one fixed Ed25519 seed (the counting
seed `00 01 … 1f`), and the token `sigtoken.SignWith` mints for that body:
`base64url(body) "." base64url(signature)`.

`signers` lists every custody signer that must mint `token` byte for byte from
that seed. Today that is the raw key (`raw-ed25519`), a `custody.SoftwareKeys`
device signer (`software-keys`), and the `device` signer of the
`custody-sealedfile/device-floor.json` blob (`sealedfile`), which seals the same
counting seed and is opened with that vector's passphrase. Each later backend
adds its name when it lands (`tpm`, in the `tpmsim` step). Ed25519 is deterministic, and
`SignWith` refuses a signature that does not verify, so a backend that
pre-hashes the body or adds a context fails here rather than in the field.

Generated by `go test ./custody -run TestCustodySignerVectors -update` and
otherwise replayed. All keys are test-only.
