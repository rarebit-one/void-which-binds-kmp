# Device-dir vectors

A custody device's directory, as `device.Store` writes it, so another
implementation (void-which-binds-kmp's desktop reader) can read the same
directory: the record, the sealed keys, the enrolment cert and the
membership replica, and what a reader must make of them.

`sealed-enrolled.json` is a device generated with `Store.GenerateInto` over
the custody-sealedfile suite's `device-floor` blob (so the passphrase and keys
are that suite's: passphrase `correct horse battery staple`, X25519 seed
`20..3f`, `device` Ed25519 seed `00..1f`), enrolled by a genesis-signed add of
the identity `40..5f`. It then signed, through its sealed signer, an add of a
second device (Ed25519 `60..7f`, X25519 `80..9f`), so `ops.jsonl` holds both.

`files` maps each file to its contents, as written:

- `device.json`: the record, `{"id","name","algorithm","public_key","encryption_key","created_at","key_custody"}`;
  `key_custody` is `"external"` for a custody device and absent for a software one.
- `device.sealed` (hex here; `sealed_file_name`): the sealed file, holding the
  X25519 seed (no name) and the Ed25519 signer named `device`.
- `enrolment.cert`: the admitting op token and a newline.
- `ops.jsonl`: the membership replica, one op token per line. A reader trims
  each line, drops blank ones and merges them (`enrolment.Merge`).

`device`, `enrolment`, `enrolled_user`, `ops` (as `Store.Ops` reads them) and
`members` (the evaluated membership, sorted) are what a reader must report at
`now`.

Each row of `refusals` replaces one file with `contents` and names what
loading must then do: refuse with `error` (`custody-mismatch`: the sealed
file's public keys do not back the record, or a software record opened with
custody keys; `malformed`: an unreadable record), or load with `enrolment`
(a cert for another device is ignored, not refused). The public-key checks
need no passphrase.

Generated by `go test ./device -run TestDeviceDirVectors -update` and
otherwise replayed. The device id is random, so re-mint only when the layout
changes. All keys and the passphrase are test-only.
